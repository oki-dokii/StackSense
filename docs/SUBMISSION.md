## Engine/source

- [ ] Original implementation developed during challenge window; owner-reviewed logic/research.
- [ ] Standard fields and hidden-style scenario import supported.
- [ ] All four core layers, supporting services, alternatives/trade-offs/drivers present.
- [ ] Cost bands, assumptions, warnings and invalid/infeasible statuses verified.
- [ ] No name/ID hard-coding; deterministic output; no LLM selection.
- [ ] No paid key required; LLM disabling documented if present.
- [ ] Exact runtime/dependency versions, lockfile and copyable local commands recorded.
- [ ] Clean setup <15 minutes and response target measured; limitations honestly stated.

## Evidence/report

- [ ] Actual P1–P6 outputs generated by final version and schema checked.
- [ ] Screenshots from actual running engine for six public cases and all edge categories.
- [ ] At least two public cases discussed in depth.
- [ ] Report sections numbered per template; sections 1–10 ≤15 A4 pages, body 10–12 pt; appendices ≤10 pages.
- [ ] Owner identity/title details filled; no placeholder values left.
- [ ] All sources/tools/libraries cited; AI assistance declaration complete.
- [ ] README architecture diagram, module flow, setup, scenario run/export and credits complete.

## Packaging and submission

- [ ] Under 1 GB; no node_modules, virtualenv, build output, large binaries or secrets.
- [ ] Public GitHub link recommended in README; history preserved.
- [ ] Drive folder named exactly as required, sharing “Anyone with the link: Viewer.”
- [ ] Access verified in private browser window.
- [ ] Folder link submitted on Unstop before **15 November 2026, 23:59 IST**.
- [ ] No files added/changed in submitted folder after deadline.

No boxes are prechecked: this starter does not provide application code, outputs, screenshots, or final report.
